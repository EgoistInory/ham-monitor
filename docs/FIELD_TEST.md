# 现场声学探针实测记录（FIELD_TEST）

> 目的：在正式开启夜间无人值守前，先用 `scripts/probe_mic.py` 实测闲置主机内置麦（及可选备用手机）在卧室实际摆放位置的底噪基线与信噪比，避免凭空拍脑袋定阈值。

## 1. 测试环境信息

- **日期**：YYYY-MM-DD
- **主机与系统**：闲置笔记本 / 迷你主机（macOS / Windows / Linux）
- **拾音设备**：内置麦克风（确认已关闭系统“语音突显 / 环境降噪”）
- **摆放位置**：卧室中部桌面 / 衣柜顶（底部垫毛巾隔振）
- **环境状态**：门窗紧闭 / 空调关闭（或开启低档）

## 3. 阈值校准结论

- **低频撞击带 (`low_min_dbfs` / `low_delta_db`)**：建议设为基线以上 `+10 ~ +14 dB`
- **中高频人声带 (`high_min_dbfs` / `high_delta_db`)**：建议设为基线以上 `+12 ~ +16 dB`
- **硬件升级判断**：若楼板闷响在 20–180 Hz 的信噪比 `< 6 dB`（完全埋在内置麦底噪中），优先将旧安卓机垫海绵置于衣柜顶贴近天花板，或增配平直频响 USB 电容麦。
