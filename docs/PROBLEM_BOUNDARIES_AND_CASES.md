# 问题边界批判性审视与跨领域维权取证参考

> 很多声学工具失败，不是因为代码写得不好，而是因为一开始就**把问题定义窄了**——误以为“装个录音脚本录到声音 = 能彻底解决扰民”。本文主动质疑常见假设，并提炼跨领域真实开源项目与司法实践的工程启示。

---

## 一、 必须主动质疑的 4 个问题边界盲区

### 盲区 1：“听起来像正楼上” ≠ 物理上一定是正楼上
- **物理事实**：现代高层住宅多为现浇混凝土楼板 + 剪力墙结构，低频撞击声（蹦跳、拖椅、重低音）在固体中的传播速度远快于空气，极易发生**斜向传导与结构共振**。实际案例中，常有“听感在正上方，实测声源在斜楼上、隔壁、甚至楼下或设备层水泵/电梯井”的情况。
- **工程对策**：
  1. 先看**频谱与时间特征**：稳定周期性低频嗡鸣（50/100Hz 及谐波）大概率是空调外机、水泵、电梯或新风共振，而非人为活动；突发性 20–180Hz 撞击叠加 300–4000Hz 人声才指向人为活动。
  2. 进阶采用 **Tier 1 双节点粗窗对比**（`ceiling` 衣柜顶垫海绵 vs `room_center` 室内中部，`scripts/compare_nodes.py`），并结合外部观察（对应楼层灯光、邻居互证）交叉确认声源归属，避免指错对象导致信用破产。

### 盲区 2：“有录音就能赢” —— 孤证在执法与司法中的天花板
- **司法现实**：在中国近年的相邻噪声侵权与生活安宁权纠纷判例中，法院普遍认为**单凭当事人自录音频或未检定手机分贝 App，难以单独认定噪声超标或构成违法妨害**（易受增益、距离、剪辑质疑）。
- **真正推动执法/判决的“证据组合拳”**：
  1. **规律性与长期性证据**（本工具自动产出的连续多周时间轴 + 哈希链 + 日报）；
  2. **前置劝阻留痕**（物业书面报修/整改通知、社区居委会/网格员调解记录——这是触发治安管理处罚的关键前置门槛）；
  3. **公权力出警记录**（110 报警记录、受案回执、民警执法记录仪）；
  4. **第三方互证**（同楼层/相邻户邻居证言、沟通记录中对方自认内容）；
  5. **硬核升级项**（正式起诉时的 CMA 资质第三方夜间检测报告、医疗诊断记录、必要时申请**诉前禁止令**）。
- **工程对策**：本系统内置 `corroboration_logs` 外部互证台账（`scripts/log_corroboration.py`），把非声学证据与声学事件统一沉淀在同一条可追溯时间轴中。

### 盲区 3：“只要记录本地时间戳就行” —— 事后伪造质疑
- **质疑场景**：如果对方抗辩“这些文件是你今天改了电脑系统时间补录的”，普通文件夹里的 WAV/MP3 很难自证清白。
- **工程对策**：借鉴数字取证领域的 **ProofMode + OpenTimestamps** 范式：
  - 本项目采用**追加式 SHA-256 哈希链（`prev_chain_hash -> chain_hash`）**，事后删除或插入中间记录会直接破坏整条链；
  - 支持导出**零音频的纯哈希清单 `TIMESTAMP_MANIFEST.txt`**，用户可将其通过 OpenTimestamps (`ots stamp`) 或国内权威电子存证/可信时间戳平台锚定，在**不泄露任何音频隐私**的前提下证明“这批证据在某日期前已客观存在”。

### 盲区 4：“只盯当前租客” —— 激励错位导致换茬复发
- **结构性本质**：若涉事房屋是出租房且房东零违规成本，赶走一任高频夜间扰民租客（如深夜直播间、作息颠倒群租）后，房东仍可能继续租给同画像租客。
- **治本逻辑**：合法合规地提高违规出租的综合管理成本——例如通过规范留痕的物业/社区劝阻、110 多次出警记录、以及在存在事实依据时依法向 12345/街道/住建/市场监管反映“住宅违规改商用（《民法典》第279条）”“未按规租赁备案或消防/群租隐患”，并在必要时向房东送达书面风险告知。

## 三、 声源归因排查清单（行动前先自查 5 分钟）

在向楼上或物业正式交涉前，建议先完成以下排查，确保站得住脚：

1. **排除本户内部源**：关闭冰箱/空调/空气净化器/路由器电源测试 1 分钟，确认底噪无异常周期峰值。
2. **排除窗外与公共设施**：核对触发时间是否与垃圾车、飙车、电梯启停、水泵切换重合（可用 `probe_mic.py` 对比开窗/关窗频谱）。
3. **交叉验证空间方向**：条件允许时用闲置手机垫海绵置于衣柜顶（`ceiling`）与桌面节点（`room_center`）同步录一晚，用 `scripts/compare_nodes.py` 验证顶部能量是否显著高于中部。
4. **联合同楼栋受影响邻居**：核对上下左右邻居是否在同一时间听到相同动静，既能精准锁定楼层/户号，又能形成多户互证。
